# 📚 Book Tracker - Трекер прочитанных книг

**Автор:** Николаев Валерий

**GitHub:** https://github.com/freak12345677/Book-Tracker-.git

## 📖 Описание

Book Tracker — это графическое приложение на Python с использованием библиотеки Tkinter для управления списком прочитанных книг. Программа помогает вести учёт прочитанной литературы, фильтровать книги по жанру и количеству страниц, сохранять данные в JSON и отслеживать статистику чтения.

## 🚀 Функциональность

- ✅ Добавление книг с указанием названия, автора, жанра и количества страниц
- ✅ Валидация ввода (проверка на пустые поля и корректность числа страниц)
- ✅ Фильтрация книг по жанру (с автоматическим обновлением списка жанров)
- ✅ Фильтрация книг по количеству страниц (операторы: >, >=, <, <=)
- ✅ Сохранение и загрузка данных в/из JSON файла
- ✅ Удаление выбранной книги
- ✅ Очистка всего списка книг
- ✅ Отображение статистики (количество книг и общее число страниц)
- ✅ Контекстное меню для быстрого удаления
- ✅ Автосохранение при каждом изменении

## 🛠 Установка и запуск

### Требования
- Python 3.6 или выше
- Стандартные библиотеки: `tkinter`, `json`, `os`
